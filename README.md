#TP1 -Mon assistant de révision
## présentation 
Dans ce TP,j'explique le programme 'main.py du TP1.
ce programme demande à l'utilisateur son prénom, la matière qu'il doit réviser et la durée de révision, puis il va affiche un message personalisé
## versions V1 à V4
**V1:** il affiche le message initial de bienvenue, qui a été créé en local
**V2:**  Ajout du prénom de l'utilisateur, et cela qu'intervient le premier push vers Github
**V3:** a ce niveau il y'a l'ajout de la matière à réviser sur Github, puis la récupération grace à la commande 'git pull'
**V4:** ici on ajoute la durée de la révision sur le PC, puis un nouveau 'git push' a ce niveau
## comment exécuter le programme?
la première étape c'est celle d'ouvrir le dossier 'TP_Git_Python' dans VS Code, puis cliquer sur 'main.PY'
la deuxième étape consiste a cliquer sur **Run python File** qui est en haut près de l'éditeur.
et enfin la dernière étape au niveau du terminal integré qyui va s'ouvrir,il faut saisir le prenom, la matière a réviser et la durée en minutes. en validant chaque reponse avec la touche entrée
## Commandes Git utilisées
1) "git init": permet de créer le depot local
2) "git add": sert à preparer les fichiers à enregistrer
3) git commit:permet d'enregistrer une version
4) "git push": permet d'envoyer vers Github la saisie et l'affichage de la durée
5) "git pull": permet de recuperer depuis github la saisie et l'affichage de la matière
